## Review standard

I aim to make each substantial project answer five questions:

1. **Can it run?** Clear prerequisites and reproducible setup.
2. **What does it do?** A concise architecture and threat/problem statement.
3. **What proves it?** Tests, sample inputs/outputs, screenshots, or traceable demonstrations.
4. **Where does it fail?** Known gaps, edge cases, and limitations.
5. **What is the maturity?** Prototype, validated demo, or production deployment—never implied without evidence.
